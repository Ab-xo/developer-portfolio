# Developer Portfolio

A modern personal portfolio for Abraham Gebeyehu, a full-stack software engineer and AI/ML engineer based in Addis Ababa, Ethiopia.

The site presents selected projects, technical capabilities, experience, and contact information through a responsive, animated interface.

## Technology

- React 19 and TypeScript
- Vite
- Tailwind CSS
- GSAP and Lenis for animation and smooth scrolling
- Three.js for 3D visuals

## Features

- Responsive project, experience, capabilities, and contact sections
- Structured project and profile data
- Reduced-motion support
- Animated interactions and scroll effects
- Downloadable CV and portfolio assets

## Getting started

```bash
npm install
npm run dev
```

## Commands

| Command | Purpose |
|---|---|
| `npm run dev` | Start the development server |
| `npm run lint` | Run project checks |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build |

## Content locations

- `src/data/projects.ts` — featured projects
- `src/data/experience.ts` — experience
- `src/data/capabilities.ts` — skills and capabilities
- `src/data/site.ts` — biography, contact, and navigation
- `public/` — CV, portrait, and static assets
